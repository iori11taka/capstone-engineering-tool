# Swagelok Capstone Engineering Tool v4.0

Static GitHub Pages-ready engineering training workspace.

## Run locally
Open the folder in VS Code and launch `index.html` with Live Server.

## GitHub Pages
Push the contents of this folder to a repository, then enable **Settings → Pages → Deploy from a branch → main / root**.

## Included
- Professional responsive dashboard and shared navigation chrome
- Fluid & Flow, Regulator Sizing, Joule–Thomson and Line Sizing modules
- Local case persistence
- JSON case export/import
- Generated engineering header artwork stored locally under `assets/header-engineering.png`
- No build step or external runtime dependency required
