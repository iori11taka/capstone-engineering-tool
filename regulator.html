REGULATOR SELECTION TOOL

Ayuda

Guía rápida

Completa la configuración, define Worst Case y Best Case y luego pulsa Calcular selección.

01

Configura el proceso

Selecciona unidades, tipo de fluido, media, velocidad aguas abajo, tipo de tubería y droop.

02

Define las condiciones

Worst Case: Pin mínima, Pout mínima y caudal máximo. Best Case: Pin máxima, Pout máxima y caudal mínimo.

03

Interpreta el bore

El Bore de diseño es el mayor entre Worst y Best. La herramienta busca la primera entrada de pipe/tube cuyo ID cumple el diámetro requerido.

04

Revisa candidatos

Verde = dentro de rango, ámbar = revisar, rojo = fuera de rango. Despliega cada regulador para revisar Lockup, Rated Flow, Choked Flow, MWP y Max Adj.

Importante

La herramienta sirve para sizing y selección inicial. La selección final debe validarse con catálogo y Flow Curve Generator.
